# neirymental.github.io

Общий репозиторий для публикации отдельных статичных страниц под доменом
`neirymental.github.io` — без создания нового репозитория под каждую страницу.

## Как опубликовать новую страницу

1. Создайте в корне репозитория новую папку с названием страницы, например `my-page/`.
2. Положите в неё `index.html` (и любые другие файлы страницы — картинки, css, js).
3. Закоммитьте и запушьте в ветку `main`.
4. Через 1-2 минуты страница появится по адресу:
   `https://neirymental.github.io/my-page/`
5. Сейчас `index.html` в корне — заглушка без ссылок на страницы (сделано
   намеренно, чтобы не выдавать список публикаций всем подряд). При желании
   в него можно вернуть список — на публикацию отдельных страниц это не влияет.

## Структура

```
/
├── index.html              — заглушка на корневом урле (без ссылок на страницы)
├── ice-bath-report/
│   └── index.html          → https://neirymental.github.io/ice-bath-report/
└── <новая-страница>/
    └── index.html          → https://neirymental.github.io/<новая-страница>/
```

## Настройки GitHub Pages

Settings → Pages → Source: Deploy from branch, ветка `main`, папка `/ (root)`.

## ⚠️ Репозиторий публичный

Этот репозиторий публичный (это требование бесплатного GitHub Pages) — всё,
что попадёт в `main`, сразу видно любому человеку в интернете, включая полную
историю коммитов. Отдельной приватности между страницами внутри репозитория нет.

## Чек-лист перед пушем в main

- [ ] В папке страницы нет черновиков, внутренних заметок и незаконченного контента — только то, что готово к публичному показу.
- [ ] В файлах нет токенов, ключей, паролей и другой служебной информации.
- [ ] Персональные и чувствительные данные (например, о респондентах) проверены и намеренно согласованы к публикации.
- [ ] Страница добавляется как новая папка в корне, а не поверх уже опубликованной чужой страницы.
- [ ] Если страница ещё не готова к публикации — она пушится в отдельную ветку/PR, а не в `main`.
